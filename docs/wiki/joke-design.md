# Joke design
Tone: deadpan. The OS never admits it is Linux except in tiny places (wallpaper caption, start page footer, os-release `ID_LIKE`).
Joke direction: we poke fun at Linux binary compatibility (vs Ubuntu), never at W*ndows. Reference: https://blog.hiler.eu/win32-the-only-stable-abi/
Look: NO taskbar/panel (R, after the first hardware test): the only way to start anything is a Desktop icon. Desktop: "This PC", "Documents", "Recycle Bin" (our own launchers in `/etc/skel/Desktop`: Nemo ignores custom names for its built-in icons, so those are hidden), "Edgy", "Wi-Fi" (opens network settings), the demo exe. No terminal of any kind. Flat 10-style window borders (`/usr/share/themes/Winedows/metacity-1`, our own drawing: white square title bar, blue 1px focus border, red close hover; no minimize button since there is nowhere to minimize to), Adwaita + `~/.config/gtk-3.0/gtk.css` (square corners, blue selection), Papirus icons. Wallpapers: the ones in `/usr/share/winedows/wallpapers/` rotate in random order every 5 minutes (Cinnamon slideshow, dconf `org/cinnamon/desktop/background/slideshow`); the slideshow also picks the first one at random at login. Nothing else may set `picture-uri`, or cinnamon-slideshow switches itself off (it reads an outside change as the user picking a wallpaper).
Debian is never named in anything a user reads (wallpaper, boot menu, /etc/issue, os-release PRETTY_NAME); it stays only in technical details (`ID=debian`, package metadata).
Boot menu: GRUB theme `build/config/includes.binary/boot/grub/winedows/` (splash with the logo, "Winedows" entries), applied by `9000-winedows-bootmenu.hook.binary`.
Edgy: our own logo `edgy.svg` (an angular "e" on a blue tile, with a lightning notch; not Microsoft's artwork), PNG renders replace Firefox's window icons, blue chrome via Firefox autoconfig (`edgy.cfg` registers `edgy-chrome.css` as an agent sheet).
Start page (`start.html`) has the "compatibility benchmark" (the butt of the joke is native Linux/Ubuntu ABI instability, NOT W*ndows; Win32 via Wine is the stable ABI; ref: blog.hiler.eu/win32-the-only-stable-abi/). Keep claims obviously silly; no real company logos/assets; avoid claims that could read as a factual statement about a real product.
Stretch ideas: fake BSOD screensaver, "Updates are available" popup that is a no-op, icon extraction from exes with `wrestool`.

## Branding & site
Site palette rule: white page with light-grey section bands; purple (wine) and blue only as small accents (headline, bars, card tops, buttons; no top stripe). NEVER tint whole sections purple.
Product brand is "GigaHard Winedows" (shorthand "Winedows" wherever text space is limited, e.g. the website `<title>`; see "Rules" below) (parody of a certain Redmond company). Logo: `docs/logo.svg` (copied to `/usr/share/winedows/logo.svg` in the image): four panes, two wine-red (glass, grapes), two blue (swoosh). Website (`docs/index.html`) is deliberately flat and corporate: white/light-grey, blue accent, top nav, cards and a table, no gradients, NO dark mode on purpose (light only: too good for this site). Keep it that way.

## Linux Torvalds easter egg
Image: `docs/linux-torvalds.png` (also `/usr/share/winedows/linux-torvalds.png` in the image). Hidden on the website: type "linus" or click the logo 5 times to reveal the "endorsement" section (fictional quote, labelled "allegedly"). In the ISO, double-clicking "Totally Native Linux App.exe" on the Desktop opens a Win32 window with the image (embedded as a BITMAP resource from `scripts/assets/linux-torvalds.bmp`) and the "Stable ABI, as promised" text. Keep it hidden; do not link it from the nav.
Also hidden in the rotating wallpapers (`scripts/gen-wallpapers.py`, the same PNG embedded): 04-vineyard (standing in a vine row), 06-no-problems (centre of the code square), 09-constellation (faint "Linux Torvalds Minor", lower left). Always this image, never a plain Tux or a redrawn penguin (R). Keep him small; never on the default wallpaper.

## Rules (hard)
- **Only Cinnamon + Firefox (branded "Edgy", spoofs the Edge UA) + Wine**, plus the minimum to boot and run them. No office suites, media players, software centers. No terminal at all (a command line is something you download as an .exe) and no taskbar: everything launches from the Desktop.
- **Joke direction:** mock Linux (Ubuntu) binary compatibility, never W*ndows. Keep it deadpan. Punchline: "Linux, but it works": Win32 via Wine is the stable ABI on Linux.
- **Parody only:** no Microsoft logos, fonts, wallpapers, sounds or trademarked product artwork. Our names: Winedows, This PC, Recycle Bin, Edgy.
- **Product name:** full brand **GigaHard Winedows** in headings, the logo, the README title and formal copy; shorthand **Winedows** wherever space is limited (page `<title>`, buttons, nav/tab labels, window titles, file/package/hostname identifiers, release titles, commit messages). When unsure, use the shorthand.
- **Naming rule:** never write the real OS name (W-i-n-d-o-w-s) anywhere in the repo: code, docs, comments, site, commit messages. Censor it as **W*ndows** (`Winedows`, `Win32`, `WINEDOWS` are fine). Where a tool needs the real token (Edge UA in policies.json, the mingw header/flag), assemble it from fragments at build time as `scripts/build-test-exes.sh` and `0200-winedows-branding.hook.chroot` do. Check: `git grep -niI windows | grep -v 'W\*ndows'` must be empty.
