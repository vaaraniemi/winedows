# Joke design
Tone: deadpan. The OS never admits it is Linux except in tiny places (wallpaper caption, start page footer, os-release `ID_LIKE`).
Look: bottom panel, Start-style menu applet at left, grouped window list, tray + clock at right; wallpaper `wallpaper.svg`; Papirus icons; desktop icons "This PC", "Recycle Bin", "Internet Exploder", "Command Prompt", demo exe.
Start page (`start.html`) has the "compatibility benchmark". Keep claims obviously silly; no real company logos/assets; avoid claims that could read as a factual statement about a real product.
Stretch ideas: fake BSOD screensaver, "Updates are available" popup that is a no-op, GRUB entry rename, icon extraction from exes with `wrestool`.
