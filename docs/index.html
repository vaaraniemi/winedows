What is it?

A Linux desktop dressed up as W*ndows. Double-click any .exe and it just runs. On Linux, the most stable ABI turned out to be Win32. We just stopped fighting it.

  • Start-style menu, taskbar, "This PC" and "Recycle Bin"
  • "Edgy", a browser that tells every website it's Edge
  • A "Command Prompt" that says 'sudo' is not recognized as an internal or external command
  • No package manager. We removed it. You're welcome.

Binary compatibility benchmark

Percentage of ten-year-old programs that still start when you double-click them (higher is better).

Ubuntu, native Linux binaries
23% — "error while loading shared libraries: libpng12.so.0"
Ubuntu, after "just recompile it"
41% — "which distro? which glibc? which Qt?"
Winedows, Win32 binaries
100% — double-click, it runs
Methodology: we double-clicked things. Inspired by “Win32 is the only stable ABI on Linux” — it is funny because it is true.

Try it

  1. Download the ISO above (verify with SHA256SUMS).
  2. Boot it in VirtualBox, QEMU, or from a USB stick (dd or Rufus in DD mode). Login is automatic.
  3. Double-click Totally Native Linux App.exe on the desktop.
qemu-system-x86_64 -enable-kvm -m 4096 -cdrom winedows.iso

If the download is split into parts, join them first: cat winedows-*.iso.part* > winedows.iso

Under the hood (the spoiler)

Debian 13 "trixie" + Cinnamon + Firefox ESR + Wine, assembled with live-build. apt is purged in the last build step. Source on GitHub.
